Persistent Stopwatch

A stopwatch for Linux that never loses time.

Close it, suspend, reboot, come back days later: the time is still right. It stores the moment you pressed start instead of counting ticks, so there is nothing running that can be stopped.

Install Source code

What it does

  • Survives everything. Restarts, crashes, suspend and reboots do not stop the clock.
  • Laps. Splits and totals, fastest in green, slowest in red, copy them all as a table.
  • Undo. Reset by accident? Ctrl+Z brings back the time and the laps.
  • Command line. Start, pause, lap, reset and read the time without opening a window, even over SSH.
  • Native on Plasma. Built with Kirigami, follows your theme, fonts and icons.

Install

One command

Detects Fedora, Debian, Ubuntu or Arch and installs the right package:

curl -fsSL https://aaghashm.github.io/persistent-stopwatch/install.sh | sh

Prefer to see what runs first? Read install.sh. Or use your package manager directly:

Fedora 44 or newer. dnf installs straight from the release URL and pulls in the KDE libraries:

sudo dnf install https://github.com/aaghashm/persistent-stopwatch/releases/latest/download/persistent-stopwatch.$(uname -m).rpm

Debian 13, Ubuntu 25.04 or newer (they ship KDE Frameworks 6):

arch=$(dpkg --print-architecture)
curl -fLO https://github.com/aaghashm/persistent-stopwatch/releases/latest/download/persistent-stopwatch_$arch.deb
sudo apt install ./persistent-stopwatch_$arch.deb

Build the package with the PKGBUILD in the repository:

git clone https://github.com/aaghashm/persistent-stopwatch
cd persistent-stopwatch/packaging/arch
makepkg -si

Needs CMake, extra-cmake-modules, Qt 6.6+ and KDE Frameworks 6 (Kirigami, Config, CoreAddons, Crash, DBusAddons, I18n, WindowSystem).

git clone https://github.com/aaghashm/persistent-stopwatch
cd persistent-stopwatch
cmake -B build -G Ninja
cmake --build build
sudo cmake --install build

Use it

Open Persistent Stopwatch from your app menu. In the window:

Space
start or pause
L
lap
R
reset
Ctrl+Z
undo the reset

From the command line

The window is optional. If it is open, commands are sent to it; if not, the saved state is updated and nothing is shown.

# time a build
persistent-stopwatch --reset --start
make
persistent-stopwatch --pause --status
Paused 00:04:12.7 (started 2026-09-05T10:31:08)

# laps, tab separated: number, split, total
persistent-stopwatch --laps
1	00:01:02.4	00:01:02.4
2	00:00:58.9	00:02:01.3
OptionDoes
--startstart, or resume if paused
--pausepause
--togglepause if running, start otherwise
--laprecord a lap
--resetback to zero, laps cleared
--statusprint state, time and start time
--lapsprint the laps

Tip: bind persistent-stopwatch --toggle to a global shortcut (System Settings, Keyboard, Shortcuts) and time things without touching the window. man persistent-stopwatch has the rest.

How it works

Most stopwatches add up timer ticks while they run, so the count dies with the process. This one saves three facts on every button press: the state, the time accumulated before the last start, and the wall-clock moment of that start. Elapsed time is always computed from those. A wall clock that jumps backward (NTP, a dead RTC battery) is clamped so the time can never shrink.

The state lives in ~/.local/state/persistentstopwatchstaterc.
