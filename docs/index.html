Persistent Stopwatch

A stopwatch for Linux that never loses time.

Close it, suspend, reboot, come back days later: the time is still right. It stores the moment you pressed start instead of counting ticks, so there is nothing running that can be stopped.

Install Source code

What it does

  • Survives everything. Restarts, crashes, suspend and reboots do not stop the clock.
  • Laps. Splits and totals, fastest in green, slowest in red, copy them all as a table.
  • Undo. Reset by accident? Ctrl+Z brings back the time and the laps.
  • Command line. Start, pause, lap, reset and read the time without opening a window, even over SSH.
  • Native on Plasma. Built with Kirigami, follows your theme, fonts and icons.
